# Antigravity Remote (Android)

Нативний Android-клієнт (WebView-обгортка на Kotlin + Jetpack Compose) для роботи з веб-інтерфейсом `https://antigravity.google.com/remote/`.

## Можливості
- **Авторизація Google OAuth:** Підміна User-Agent для обходу помилки `403 disallowed_useragent`, підтримка спливаючих вікон (`onCreateWindow`) та системних інтентів 2FA/Passkeys.
- **Збереження сесії:** Примусова синхронізація `CookieManager` та `DOM Storage` між перезапусками.
- **Робота з файлами:** Мульти-вибір файлів для завантаження у чат та підтримка скачування згенерованих артефактів (включаючи `blob:` та `data:` URL).
- **Зручна навігація:** Нижня панель керування з автоприховуванням під час відкриття клавіатури, перемикач режимів `MOB / PC` (Mobile / Desktop) та історія кастомних URL.

## Як завантажити готовий APK
1. Перейдіть у вкладку **Actions** у цьому репозиторії на GitHub.
2. Відкрийте останній успішний запуск воркфлоу **Android APK Build**.
3. Унизу сторінки в блоці **Artifacts** завантажте:
   - `Antigravity-Remote-Release` (оптимізована, стиснута версія для щоденного використання)
   - або `Antigravity-Remote-Debug` (відлагоджувальна версія).
4. Розпакуйте ZIP-архів та встановіть `.apk` на смартфон.
